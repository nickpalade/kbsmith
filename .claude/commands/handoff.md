---
description: End-of-session handoff so the next fresh session (after /clear) starts instantly
---
Write the handoff into the KB, not the chat:
1. Status page: STATUS, one dated LOG line (what was done, what was verified, what was not), NEXT
   as concrete checkboxes with file paths.
2. Anything half-done: exact state, the next command to run, open questions (-> `kb/12`).
3. Lessons -> `kb/25`, decisions -> `kb/11`, user preferences learned today -> `kb/08`.
4. Commit the KB. Then tell the human in 3 lines what the next session should start with.
After this, `/clear` loses nothing.
