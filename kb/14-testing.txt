TESTING

WHAT CLAUDE RUNS ALONE
npm test, node --check on touched .mjs files, kb-lint, `node bin/kbsmith.mjs init` into a temp folder.

WHAT THE HUMAN CHECKS
The one-prompt install in a real Claude Code session; README tone; anything pushed to GitHub.

HOW TO TEST
npm test  -> "pass 23, fail 0" (2026-11-11)
node .kbsmith/scripts/kb-lint.mjs  -> "kb-lint: ok (0 warning(s))"

BUG HUNTING ROUTINE
1. Reproduce first, with the exact steps and output.
2. One hypothesis at a time; prove or kill it with evidence.
3. Fix the root cause and keep the test that caught it.
4. Two failed fixes -> /postmortem.
